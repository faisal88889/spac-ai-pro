# 🚀 SPAC AI Pro - تطبيق تداول احترافي

تطبيق جوال متكامل للتداول مع TradingView ومحفظة وتنبيهات ذكية.

## 📱 المميزات

- 📈 **TradingView احترافي** - رسوم بيانية حقيقية
- 💼 **محفظة تفاعلية** - تتبع الأرباح والخسائر
- 🔔 **تنبيهات Push** - إشعارات فورية
- 🤖 **تحليل AI** - توصيات ذكية
- 💾 **حفظ محلي** - البيانات على جهازك
- 🌐 **عربي كامل** - دعم RTL

## 🚀 التشغيل السريع

### الطريقة 1: Expo Go (الأسرع)

1. حمّل تطبيق **Expo Go** من المتجر
2. امسح رمز QR أدناه
3. التطبيق يفتح مباشرة

### الطريقة 2: تشغيل محلي

```bash
# تثبيت المكتبات
npm install

# تشغيل التطبيق
npx expo start
```

## 📦 البناء للإنتاج

```bash
# Android APK
expo build:android

# iOS IPA
expo build:ios
```
